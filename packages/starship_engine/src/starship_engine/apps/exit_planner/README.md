# Exit Planner App

Purpose
Computes exit targets and ETA guidance for trades (advisory only).

Key Modules
- `app.py`
- `planner.py`
- `targets.py`
- `eta.py`
- `settings.py`

Configuration
Settings defaults live in `settings.py` and can be overridden by root config (e.g. `configs/bot.yaml`) or env vars.
